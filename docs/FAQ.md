# 常見問題

## 安裝與啟動

### Q1：為什麼下載後不能直接執行？

本專案提供**非 Self-Contained** 版本，需先安裝 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)。請確認下載的 Runtime 架構與 zip 相符：

- `win-x64` → x64 Desktop Runtime
- `win-arm64` → ARM64 Desktop Runtime

### Q2：有安裝程式嗎？

沒有。本專案只提供 zip 壓縮檔，解壓縮後直接執行 `MiniScreenNotes.exe`。移除時刪除資料夾即可。

### Q3：Windows 顯示「未知的發行者」怎麼辦？

目前執行檔未進行程式碼簽章，SmartScreen 會顯示警告。若檔案來自本專案 GitHub Releases，可選擇「更多資訊」→「仍要執行」。請勿執行來源不明的檔案。

### Q4：啟動後沒有畫面？

- 確認 `.NET 10 Desktop Runtime` 已安裝。
- 查看 `%AppData%\MiniScreenNotes\error.log`。
- 程式可能以 `--minimized` 啟動，請從系統匣圖示或按 `Ctrl+Alt+A` 顯示面板。

## 操作

### Q5：如何快速顯示或隱藏面板？

預設按 `Ctrl+Alt+A`。也可從系統匣圖示左鍵切換，或使用右鍵選單。快捷鍵可在設定中自訂。

### Q6：游標模式是什麼？

游標模式會讓覆蓋層點擊穿透，滑鼠可以正常操作底層視窗。按滑鼠中鍵或點擊游標工具即可切換。關閉游標模式後會恢復原本選取的標註工具。

### Q7：為什麼中鍵切換沒有反應？

請確認浮動面板目前可見；面板隱藏時不會攔截中鍵。部分滑鼠驅動程式或防毒軟體可能攔截低階滑鼠事件，可改用面板上的游標按鈕。

### Q8：面板不見了怎麼找回來？

- 按 `Ctrl+Alt+A`。
- 從系統匣選單選擇「顯示 / 隱藏浮動面板」。
- 若面板位置在已拔除的螢幕上，程式會自動校正到可用螢幕；若仍異常，可刪除 `config.json` 重新建立預設組態。

### Q9：如何重設步驟編號？

選取「步驟編號」工具後，在畫布上按滑鼠右鍵即可重設為 1。

### Q10：放大鏡怎麼調整？

- 滑鼠滾輪：調整 1x～10x 倍率。
- `Ctrl+滾輪`：調整鏡頭直徑 200～500 DIP。

### Q11：聚光燈範圍怎麼調整？

使用聚光燈工具時滾動滑鼠滾輪，半徑範圍為 60～450 DIP。

## 儲存與輸出

### Q12：標註會自動保存嗎？

不會。標註只存在記憶體中，關閉程式後消失。需要保留時請使用複製或儲存功能。

### Q13：一鍵快速儲存是什麼？

啟用後，點擊儲存不會跳出檔案對話框，而是直接將目前螢幕存到指定資料夾，檔名自動加上時間戳記。可在設定中選擇 PNG 或 JPEG。

### Q14：複製的內容包含滑鼠游標嗎？

不包含。擷取的是螢幕畫面與標註，不包含系統游標。

### Q15：為什麼截圖中看得到面板或放大鏡？

排除視窗擷取需要 Windows 10 2004（Build 19041）以上。較舊版本仍可執行，但 `WDA_EXCLUDEFROMCAPTURE` 效果會降級或無效。

## 多螢幕與 DPI

### Q16：支援多螢幕嗎？

支援。程式會為每個實體螢幕建立一個覆蓋層，並以 Per-Monitor DPI v2 處理不同縮放比例。

### Q17：支援混合 DPI 嗎？

支援。不過混合 DPI 與多螢幕組合的實機情境仍需更多驗證，若遇到位置偏移請回報。

### Q18：拔掉螢幕後面板跑到螢幕外？

程式會將面板限制在可用螢幕範圍內。若仍發生，可刪除 `%AppData%\MiniScreenNotes\config.json` 讓設定重新建立。

## 個人化

### Q19：可以自訂面板上的工具嗎？

可以。設定 →「工具項目與排序」可勾選顯示的工具、調整順序，並設定每列／每行上限。

### Q20：可以建立多組面板設定嗎？

可以。設定視窗頂部可複製新增、重新命名與刪除組態。每組會各自記住尺寸、方向、主題、工具與位置。

### Q21：有哪些主題？

共 10 種：黃色護眼、冰河藍、森林綠、靛藍紫、玫瑰紅、暮光橘、海洋青、櫻花粉、摩卡棕、石墨灰。每種都有淺色與深色版本，並可選擇跟隨系統。

### Q22：如何開機自動啟動？

可從系統匣選單勾選「開機自動啟動」，或在設定 →「快捷鍵與系統」啟用。程式會以 `--minimized` 常駐系統匣。

## 隱私與資料

### Q23：程式會連網或上傳畫面嗎？

不會。程式沒有網路功能、沒有遙測，也不收集使用資料。

### Q24：設定檔在哪裡？

`%AppData%\MiniScreenNotes\config.json`。錯誤記錄在 `%AppData%\MiniScreenNotes\error.log`。

### Q25：可以攜帶設定到另一台電腦嗎？

可以手動複製 `config.json`。但面板位置與多螢幕配置可能不同，程式會自動校正到可用範圍。

## 開發與授權

### Q26：可以自行編譯嗎？

可以。請安裝 .NET 10 SDK，執行：

```powershell
dotnet build MiniScreenNotes.sln
dotnet test MiniScreenNotes.sln
```
