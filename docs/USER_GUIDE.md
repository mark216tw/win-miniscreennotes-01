# 使用指南

本文件說明 mini螢幕筆記（MiniScreenNotes）的安裝、面板操作、標註工具與設定方式。

## 1. 取得與啟動

1. 從 [GitHub Releases](https://github.com/mark216tw/win-miniscreennotes-01/releases/latest) 下載符合裝置的壓縮檔：
   - 一般 Intel／AMD 電腦：`win-x64`
   - Windows on ARM：`win-arm64`
2. 解壓縮到任意資料夾（例如 `C:\Tools\MiniScreenNotes`）。
3. 安裝 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)。非 Self-Contained 版本不會附帶執行環境。
4. 執行 `MiniScreenNotes.exe`。

程式啟動後會顯示浮動工具面板，並常駐於系統匣。若以 `--minimized` 參數啟動，面板不會自動顯示，只會常駐系統匣（開機自動啟動即使用此模式）。

本專案不提供安裝程式；移除時結束程式、刪除解壓縮資料夾，並視需要清除 `%AppData%\MiniScreenNotes` 即可。

## 2. 系統匣操作

在工作列通知區域的 mini螢幕筆記圖示上按一下：

- 左鍵：顯示／隱藏浮動面板。
- 右鍵：開啟選單。

系統匣選單包含：

| 項目 | 說明 |
| --- | --- |
| 顯示 / 隱藏浮動面板 | 切換工具面板可見狀態 |
| 面板組態 | 快速切換已儲存的面板組態 |
| 清除所有標註 | 清除目前所有螢幕上的標註（可復原） |
| 開機自動啟動 | 登錄 Windows 開機啟動 |
| 設定... | 開啟設定視窗 |
| 關於 mini螢幕筆記 | 顯示版本、授權與隱私說明 |
| 結束應用程式 | 儲存面板位置並結束程式 |

## 3. 浮動工具面板

### 移動與排列

- 按住面板空白處即可拖曳整個面板。
- 面板尺寸分為特小、小、中、大；圖示與按鈕會依尺寸縮放。
- 橫向面板適合放在螢幕上緣或下緣；直向面板適合放在左緣或右緣。
- 工具數量超過「每列／每行工具數量上限」時會自動折行或折列。

### 邊緣吸附與自動隱藏

- 將面板拖到可吸附的螢幕邊緣附近（24 DIP 內）後放開，即會吸附。
- 橫向面板只吸附上／下緣；直向面板只吸附左／右緣。
- 啟用「吸附到螢幕邊緣後自動隱藏為小手把」後，滑鼠離開面板達指定秒數，面板會收合為貼齊邊緣的小手把。
- 滑鼠移入小手把會立即展開面板；點擊小手把也可展開。
- 收合為小手把時，螢幕上的標註仍會保持顯示。
- 使用快捷鍵或系統匣隱藏面板時，標註與白板／黑板背景會一併隱藏，再次顯示面板時恢復。
- 每個面板組態會各自記住位置與吸附邊緣；螢幕解析度變更或多螢幕拔除時，面板會自動回到可用螢幕範圍內。

### 面板上的固定按鈕

| 按鈕 | 說明 |
| --- | --- |
| 設定 | 開啟設定視窗 |
| 關閉 | 隱藏面板（程式仍在系統匣執行） |

## 4. 標註工具

選取工具後直接在任一螢幕上操作。除了游標模式外，覆蓋畫布會攔截滑鼠事件，底層視窗在切換回游標模式前不會收到點擊。

| 工具 | 操作 | 備註 |
| --- | --- | --- |
| 游標模式 | 點擊游標按鈕或按滑鼠中鍵 | 滑鼠事件穿透至底層視窗；關閉游標模式會恢復原本選取的標註工具 |
| 畫筆 | 按住左鍵拖曳 | 以二次貝茲曲線平滑化，適合手寫與圈選 |
| 螢光筆 | 按住左鍵拖曳 | 半透明、不疊色，寬度約為線寬的 3.5 倍 |
| 直線 | 拖曳 | 按住 `Shift` 鎖定 0°、45°、90° 等 45° 倍數角度 |
| 箭頭 | 拖曳 | 按住 `Shift` 鎖定角度 |
| 空心矩形 | 拖曳 | 按住 `Shift` 鎖定正方形 |
| 實心矩形 | 拖曳 | 按住 `Shift` 鎖定正方形 |
| 空心橢圓 | 拖曳 | 按住 `Shift` 鎖定正圓 |
| 實心橢圓 | 拖曳 | 按住 `Shift` 鎖定正圓 |
| 綠色打勾 | 點擊放置；拖曳調整大小 | 固定綠色圖章 |
| 紅色打叉 | 點擊放置；拖曳調整大小 | 固定紅色圖章 |
| 文字標註 | 點擊輸入文字 | `Ctrl+Enter` 確認、`Esc` 取消；失去焦點也會自動確認 |
| 步驟編號 | 點擊放置 | 自動遞增 ①②③；標註模式下按滑鼠右鍵會清空所有標註並重設為 1 |
| 橡皮擦 | 拖曳 | 擦除碰觸到的標註，可復原 |
| 雷射筆 | 移動滑鼠 | 顯示約 1.2 秒的彗星拖尾，不留下永久標註 |
| 聚光燈 | 移動滑鼠 | 四周變暗、中央透光；滾輪調整半徑（60～450 DIP） |
| 放大鏡 | 移動滑鼠 | 滾輪調整倍率 1x～10x；`Ctrl+滾輪` 調整鏡頭直徑 200～500 DIP |

### 顏色與線寬

- 點擊顏色按鈕開啟色票，選擇後套用至後續標註。
- 點擊線寬按鈕選擇預設線寬，或使用設定中的線寬選項。
- 顏色與線寬會記憶於設定檔，下次啟動沿用。

### 顯示與背景

| 功能 | 說明 |
| --- | --- |
| 顯示／隱藏標註 | 暫時隱藏所有標註，不刪除資料 |
| 背景模式 | 在透明、白板、黑板之間循環切換 |
| 復原 / 重做 | 對應 `Ctrl+Z` / `Ctrl+Y`，包含新增、擦除與清除 |
| 清除 | 清除所有標註，可復原 |
| 複製 | 將目前螢幕（含標註）複製到剪貼簿 |
| 儲存 | 儲存目前螢幕為 PNG 或 JPEG |

### 文字輸入

1. 選擇「文字標註」。
2. 在畫面上點擊要放置文字的位置。
3. 輸入文字，按 `Ctrl+Enter` 確認；按 `Esc` 取消。

文字大小會依目前線寬自動調整。

## 5. 複製與儲存

### 一般儲存

點擊儲存按鈕後會開啟檔案對話框，可選擇 PNG 或 JPEG，預設檔名為 `MiniScreenNotes_yyyyMMdd_HHmmss.png`。上次儲存的資料夾會被記住。

### 一鍵快速儲存

於設定中啟用後，點擊儲存會直接寫入指定資料夾，不顯示對話框：

- 支援 PNG（無損）與 JPEG（品質 92）。
- 檔名自動加上時間戳記。
- 完成後顯示提示，並可點擊提示開啟資料夾。

### 複製到剪貼簿

點擊複製按鈕，會將目前游標所在螢幕的畫面與標註複製到剪貼簿，可直接貼到其他應用程式。

## 6. 設定視窗

設定視窗分為三個分頁；變更會即時套用並自動儲存。

### 面板與外觀

| 設定 | 說明 |
| --- | --- |
| 面板大小 | 特小 24px、小 30px、中 38px、大 46px |
| 面板方向 | 橫向（吸附上／下緣）或直向（吸附左／右緣） |
| 顯示模式 | 跟隨系統、淺色、深色 |
| 主題顏色 | 10 種主題，每種皆提供淺色與深色版本 |
| 工具數量上限 | 每列／每行最多顯示的工具數量，範圍 1～26 |
| 自動隱藏 | 吸附後自動收合為小手把，延遲 0.5～30 秒 |

### 工具項目與排序

- 勾選要顯示在面板上的工具與功能項目。
- 使用「上移」、「下移」調整順序。
- 「全部顯示」可一次勾選所有項目。

### 快捷鍵與系統

| 設定 | 說明 |
| --- | --- |
| 全域快捷鍵 | 勾選 `Ctrl`、`Alt`、`Shift` 並選擇按鍵，按「套用快捷鍵」生效；預設 `Ctrl+Alt+A` |
| 滑鼠中鍵切換 | 面板顯示時以滑鼠中鍵切換游標模式；可取消勾選以避免中鍵被其他程式攔截 |
| 一鍵快速儲存 | 啟用靜默存檔、指定資料夾與圖片格式 |
| 開機自動啟動 | 登錄 Windows 開機啟動，並以 `--minimized` 常駐系統匣 |

若快捷鍵已被其他程式占用，設定頁會顯示失敗訊息，並保留原本已生效的快捷鍵。

### 關於視窗

點擊設定視窗底部的「關於」按鈕，可開啟關於視窗，內容包含：

- 版本、檔案版本、授權與隱私說明。
- 系統資訊：作業系統、系統／處理程序架構、.NET 執行環境、顯示器解析度與縮放、資料位置，以及目前的全域快捷鍵。
- 完整快捷鍵清單：面板顯示／隱藏、游標模式、復原／重做、複製／儲存、文字輸入、放大鏡、聚光燈與步驟編號操作。

系統匣右鍵選單也提供「關於 mini螢幕筆記」入口。

### 面板組態管理

設定視窗頂部可管理多組面板組態：

| 操作 | 說明 |
| --- | --- |
| 複製新增 | 以目前組態為範本建立新組態 |
| 重新命名 | 修改目前組態名稱 |
| 刪除 | 刪除目前組態；需二次確認 |

每組組態各自保存尺寸、方向、顯示模式、主題、工具顯示與順序、位置、吸附邊緣、自動隱藏設定。切換組態會即時套用並記住原組態位置。

## 7. 快捷鍵與滑鼠

| 操作 | 快捷鍵 |
| --- | --- |
| 顯示／隱藏浮動面板 | `Ctrl+Alt+A`（可自訂） |
| 切換游標模式 | 滑鼠中鍵（面板顯示時有效，可在設定關閉） |
| 復原 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` |
| 複製目前螢幕標註 | `Ctrl+C`（面板聚焦時） |
| 儲存目前螢幕標註 | `Ctrl+S`（面板聚焦時） |
| 回到游標模式 | `Esc`（不需面板聚焦；選單或文字輸入中會先取消） |
| 確認文字輸入 | `Ctrl+Enter` |
| 取消文字輸入 | `Esc` |
| 鎖定角度／正方形／正圓 | 繪製時按住 `Shift` |
| 清空所有標註（可復原） | 標註模式下按滑鼠右鍵 |
| 調整聚光燈半徑 | 滑鼠滾輪 |
| 調整放大鏡倍率 | 滑鼠滾輪 |
| 調整放大鏡鏡頭大小 | `Ctrl+滾輪` |

## 8. 資料與移除

| 項目 | 路徑 |
| --- | --- |
| 設定檔 | `%AppData%\MiniScreenNotes\config.json` |
| 錯誤記錄 | `%AppData%\MiniScreenNotes\error.log` |
| 快速儲存預設資料夾 | `%UserProfile%\Pictures\MiniScreenNotes` |

- 設定檔以 JSON 儲存，包含面板組態、主題、快捷鍵、快速儲存與啟動設定。
- 程式不會上傳設定檔或任何畫面內容。
- 若設定檔損毀，程式會回退至預設組態並在記錄檔留下警告。

## 9. 疑難排解

| 問題 | 處理方式 |
| --- | --- |
| 雙擊後沒有畫面 | 確認已安裝 .NET 10 Desktop Runtime；查看 `%AppData%\MiniScreenNotes\error.log` |
| 全域快捷鍵無效 | 可能被其他程式占用，請到設定改用其他組合後按「套用快捷鍵」 |
| 面板找不到 | 按 `Ctrl+Alt+A` 或從系統匣選單選擇「顯示 / 隱藏浮動面板」 |
| 面板位置在螢幕外 | 程式會自動校正到可用螢幕；若仍異常，可刪除 `config.json` 重新建立預設組態 |
| 放大鏡或面板出現在截圖中 | 需要 Windows 10 2004 以上才支援排除擷取；較舊版本會降級 |
| 中鍵切換游標模式沒反應 | 確認浮動面板目前可見；部分滑鼠驅動程式可能攔截中鍵 |
| 開機沒有自動啟動 | 檢查系統匣選單的「開機自動啟動」是否勾選，或 Windows 設定中的啟動應用程式清單 |
